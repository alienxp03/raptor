# Raptor tour

[Watch the 28-second tour](raptor-tour.mp4). It uses a fictional Rex workspace and the synthetic demo backend only—no live sessions, repos, or personal data.

On-screen flow:

1. Open the session list; find a session or project.
2. Rename a session.
3. Close a session while keeping its worktree and branch.
4. Review a GitHub PR before opening it.
5. Create a worktree with an optional Pi launch.

Regenerate on macOS with `scripts/capture-tour.sh` (requires `ffmpeg`). The output is silent, captioned, and 28 seconds long.
